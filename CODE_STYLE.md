# MatrixGold React Code Style

This file is part of the authoritative project baseline. New and modified frontend code must follow `.editorconfig` and `.prettierrc.json`.

- Do not generate compressed/single-line components, hooks, handlers, JSX trees, objects, or API calls.
- Use readable multiline JSX and one logical statement per line.
- Keep internal transaction types and permission Screen_No values in code/security configuration only; do not render them beside user-facing screen titles.
- Use 2 spaces for JavaScript/JSX and a target line width of 110 characters.
- Preserve the approved MatrixGold green UI and existing component patterns.
