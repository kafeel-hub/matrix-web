# React V2.12.4

## Financial statement cell highlighting

- Trial Balance: non-zero Debit cells use a restrained red tint; non-zero Credit cells use a restrained green tint. This applies to opening, movement, closing, and gold Dr/Cr columns.
- Profit & Loss: non-zero Debit and Closing Dr cells use the same restrained red treatment; Credit and Closing Cr use green.
- Zero values remain neutral.
- Account/group rows are not recolored; existing hierarchy styling remains unchanged.
- No API, accounting calculation, filters, payloads, permissions, or routing changes.
