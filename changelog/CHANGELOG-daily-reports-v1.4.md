# Daily Reports v1.4 – Sales by Payment Type
- Adds Daily Sales Report by Payment Type to the existing Daily Reports workspace.
- Uses the dedicated payment-grain API endpoint.
- Filters: date range, current transaction type (GSAL/GRET/USAL/UGLP), and All/Cash/Non-Cash.
- Displays payment details only; no item/detail joins or item columns.
- Shows payment-type subtotals and overall payment amount.
